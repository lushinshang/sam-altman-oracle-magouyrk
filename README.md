## 200字介紹

這是兩家合作夥伴在發表會上的對談。導讀把台上說法對回書面公告：GPT-6 的推出月份，Magouyrk 說 8 月，官方發表頁標 9 月；奧特曼說 Jalapeño 晶片「正在 OCI 上部署」，Oracle 自己寫的是「計畫部署」；Oracle 超過 70% 的軟體由 AI 撰寫，只有台上這一句，沒有公布算法。最值得帶走的是奧特曼的建議：短期內如果只能做一件事，比讓 Codex 變得超級有生產力更重要的，是理解 AI 帶來的資安威脅並做防範。
